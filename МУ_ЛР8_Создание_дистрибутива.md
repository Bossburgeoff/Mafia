## 1. Цель и задачи работы

**Цель:** освоить сборку установочного пакета приложения и подготовку инструкции по установке.

**Задачи:**

- определить состав дистрибутива;
- собрать установочный пакет;
- проверить установку на «чистой» машине;
- подготовить инструкцию по установке и запуску;
- зафиксировать версию и состав сборки.

**Проектный контекст.** Работа выполняется на материале сквозного проекта «Мафия». Результат — установочный пакет, который можно передать пользователю.

## 2. Теоретические сведения

**Дистрибутив** — комплект файлов, предназначенный для установки программы на компьютер пользователя.

**Состав дистрибутива:**

| Компонент | Назначение |
|---|---|
| Исполняемые файлы | сама программа |
| Библиотеки и зависимости | то, без чего программа не запустится |
| Файлы конфигурации | настройки по умолчанию |
| База данных (при необходимости) | начальная схема |
| Документация | руководство пользователя, лицензия |
| Установщик | программа установки |

**Требования к дистрибутиву:**

1. Устанавливается на «чистую» машину без ручных доработок.
2. Не требует установки дополнительного программного обеспечения, не указанного в инструкции.
3. Понятно сообщает об ошибках установки.
4. Позволяет удалить программу без следов.
5. Имеет номер версии.

**Версионирование.** Принята схема `MAJOR.MINOR.PATCH`: `MAJOR` — несовместимые изменения, `MINOR` — новая функциональность, `PATCH` — исправления.

**Проверка на «чистой» машине** — ключевой этап: если программа работает только на компьютере разработчика, дистрибутив собран неверно.

- собранное приложение из лабораторной работы 6.

## 4. Порядок выполнения

### Шаг 1. Определить состав дистрибутива

- Выписать, какие файлы и библиотеки нужны для работы приложения.
- Определить, что устанавливается в систему, а что остаётся в папке программы.
- **Результат:** перечень состава дистрибутива.

### Шаг 2. Собрать приложение

- Собрать исполняемый вариант приложения со всеми зависимостями.
- Убедиться, что приложение запускается вне среды разработки.
- **Результат:** собранное приложение.

### Шаг 3. Создать установочный пакет

- Собрать установщик: выбрать папку установки, создать ярлык, прописать удаление.
- Присвоить версию.
- **Результат:** установочный файл.

### Шаг 4. Проверить на «чистой» машине

- Установить приложение на машину без среды разработки.
- Проверить: запуск, создание комнаты, проведение партии, удаление.
- Зафиксировать все ошибки и недостающие компоненты.
- **Результат:** протокол проверки установки.

### Шаг 5. Исправить найденные проблемы

- Дополнить дистрибутив недостающими файлами, поправить установщик.
- Пересобрать и проверить повторно.
- **Результат:** дистрибутив устанавливается без замечаний.

### Шаг 6. Подготовить инструкцию

- Описать: требования к системе, порядок установки, первый запуск, удаление.
- Приложить скриншоты ключевых шагов.
- **Результат:** `README_install` готов.

### Шаг 7. Оформить отчёт

- Описать состав дистрибутива, процесс сборки, результаты проверки.
- **Результат:** отчёт приложен.

## 5. Требования к отчёту

Отчёт содержит:

1. Титульный лист (дисциплина, работа, группа, ФИО, дата).
2. Цель работы.
3. Состав дистрибутива (перечень компонентов).
4. Версию сборки и её обоснование.
5. Порядок сборки (кратко, по шагам).
6. Протокол проверки на «чистой» машине.
7. Перечень исправленных проблем.
8. Инструкцию по установке.
9. Заполненный чек-лист приёмки.
10. Вывод.

Файлы: `ИТС31_Фамилия_ЛР8.docx`, установочный пакет, `README_install`.

## 7. Критерии оценки

| Критерий | 2 | 3 | 4 | 5 |
|---|---|---|---|---|
| Состав дистрибутива | не определён | неполный | полный | + обоснование |
| Сборка приложения | не собрано | запускается у разработчика | запускается вне среды разработки | + без лишних файлов |
| Установочный пакет | нет | устанавливается с ошибками | устанавливается | + удаление работает |
| Проверка на чистой машине | не проводилась | частичная | полная | + протокол с замечаниями |
| Инструкция | нет | краткая | полная со скриншотами | + раздел удаления |

Оценка выставляется по формуле: 60 % командный результат + 40 % личный вклад.
