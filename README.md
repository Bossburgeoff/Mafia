# Мафия Онлайн

Мультиплеерная «Мафия» на 10–12 игроков с автоматическим ведущим.

## Как запустить для друзей (бесплатно, 5 минут)
1. Создай на GitHub новый публичный репозиторий, например `mafia`.
2. Через GitHub Desktop положи в него все файлы из этой папки и сделай Push.
3. На GitHub: Settings → Pages → Branch: `main` / root → Save.
4. Через минуту игра будет доступна по ссылке вида `https://ТВОЙ_НИК.github.io/mafia/`.
5. Отправь ссылку друзьям. На телефоне: меню браузера → «Добавить на главный экран» — игра установится как приложение.

## Как играть
- Один игрок жмёт «Создать лобби» и отправляет друзьям 5-значный код.
- Остальные жмут «Присоединиться к лобби» и вводят код (или открывают ссылку `...?join=КОД`).
- Не хватает людей — создатель может добавить ботов.
- Голосом удобно общаться параллельно в Discord, а текстовый чат в игре соблюдает очередь речи.

## Важно
- Создатель лобби — это «сервер»: пока идёт партия, его вкладка должна быть открыта.
- Тест на одном компьютере без интернета: открой `index.html?local` в нескольких вкладках.
