# ♠ МАФИЯ — Mafia 2026

**Интерактивная веб-игра по мотивам классической настольной игры «Мафия».**

Мафия — это браузерный игровой проект, в котором участники получают скрытые роли, взаимодействуют друг с другом, используют специальные способности и пытаются привести свою команду к победе. Проект объединяет классическую игровую механику с современным интерфейсом, системой игровых комнат и возможностью играть с ботами.

> **Статус проекта:** Prototype v0.1. Основная задача текущей версии — продемонстрировать интерфейс, механику игры и основные игровые возможности.

## 📌 О проекте

Mafia 2026 — веб-приложение с тематическим интерфейсом, созданное для знакомства с игровой механикой «Мафии» в цифровом формате.

В проекте реализованы главное меню, профиль игрока, настройка партии, игровое поле, распределение ролей, дневные и ночные фазы, голосование, игровые сообщения и логика определения победителя.

Проект адаптирован для мобильных устройств и компьютеров.

## 🎯 Цель проекта

* Перенести классическую игру «Мафия» в браузерный формат.
* Создать понятный и удобный игровой интерфейс.
* Реализовать основные игровые роли и их способности.
* Добавить возможность проводить партии с ботами.
* Продемонстрировать навыки разработки интерактивных веб-приложений.

## ✨ Основные возможности

### 🏠 Главное меню

Главный экран содержит профиль игрока и основные разделы приложения:

* Игровые комнаты.
* Создание лобби.
* Создание лобби с ботами.
* Раздел друзей.
* Правила игры.
* Магазин.
* Настройки и статистика профиля.
* Выбор и изменение аватара.
* Изменение игрового имени.

### ⚙️ Настройка игровой комнаты

Перед началом партии можно настроить основные параметры игры:

* Количество участников — от 2 до 20.
* Количество мафиози.
* Количество ботов.
* Продолжительность дневной и ночной фаз.
* Набор доступных игровых ролей.
* Код игровой комнаты.

После настройки пользователь может запустить партию и перейти к игровому экрану.

### 🎭 Система ролей

В игре предусмотрено шесть основных ролей:

| Роль             | Описание                                                              |
| ---------------- | --------------------------------------------------------------------- |
| 🔪 Мафия         | Выбирает цель ночью и пытается устранить мирных жителей.              |
| 🕵️ Комиссар     | Проверяет выбранного игрока и узнаёт, относится ли он к мафии.        |
| 🩺 Доктор        | Может защитить игрока от ночного покушения.                           |
| 💋 Любовница     | Блокирует специальное действие выбранного игрока.                     |
| 📰 Журналист     | Сравнивает двух игроков и узнаёт, принадлежат ли они к одной команде. |
| 🧑 Мирный житель | Анализирует происходящее и участвует в дневном голосовании.           |

Роли распределяются случайным образом в начале партии. Игрок может открыть описание своей роли в специальном окне.

### 🌙 Игровой процесс

Игровой цикл состоит из двух основных фаз.

**Ночь**

* Активируются специальные способности ролей.
* Мафия выбирает цель.
* Комиссар проводит проверку.
* Доктор выбирает игрока для защиты.
* Любовница блокирует действие выбранного игрока.
* Журналист сравнивает участников.

**День**

* Игроки анализируют результаты ночи.
* Участники выбирают подозреваемого.
* Проходит голосование.
* Игрок с наибольшим количеством голосов может быть исключён из партии.
* При ничьей никто не выбывает.

Продолжительность фаз задаётся при настройке комнаты. Также предусмотрена возможность вручную переключать игровые фазы.

### 🤖 Игра с ботами

Боты используются в качестве участников партии. Они могут участвовать в голосовании и выполнять предусмотренные игровой логикой действия.

Такой режим позволяет тестировать механику игры без необходимости собирать полную команду реальных игроков.

### 💬 Игровой интерфейс

Игровой экран включает:

* Отображение личной роли.
* Список участников.
* Информацию о количестве живых игроков.
* Счётчик оставшегося времени.
* Игровой журнал.
* Поле сообщений.
* Выбор цели для действия.
* Панель голосования.
* Отображение состояния участников.

### 🏆 Условия победы

Партия завершается при выполнении одного из двух условий:

* **Победа города:** все участники мафии выбыли.
* **Победа мафии:** количество оставшихся мафиози становится не меньше количества остальных живых участников.

После завершения партии игрок получает уведомление с результатом.

## 🛠️ Технологии

Проект создан с использованием базовых веб-технологий:

* **HTML5** — структура страниц и игровых экранов.
* **CSS3** — оформление интерфейса, анимации, адаптивная вёрстка и визуальные эффекты.
* **JavaScript** — игровая логика, обработка действий пользователя, распределение ролей, управление фазами, таймеры, голосование и работа с интерфейсом.

В текущей версии HTML, CSS и JavaScript объединены в одном HTML-файле. Внешние библиотеки и серверная часть в представленном коде не используются.

## 🚀 Запуск проекта

Для локального запуска:

1. Скачайте HTML-файл проекта.
2. При необходимости переименуйте его в `index.html`.
3. Откройте файл в современном браузере.
4. Перейдите в главное меню.
5. Создайте лобби с ботами, настройте параметры и начните партию.

Дополнительная установка зависимостей для базового запуска не требуется.

## 🌐 Публикация на GitHub Pages

Проект можно разместить в интернете с помощью GitHub Pages.

1. Создайте репозиторий на GitHub.
2. Загрузите файл `index.html` и этот `README.md`.
3. Откройте настройки репозитория — **Settings**.
4. Перейдите в раздел **Pages**.
5. В качестве источника публикации выберите **Deploy from a branch**.
6. Выберите ветку `main` и папку `/ (root)`.
7. Сохраните настройки и дождитесь публикации.

После завершения публикации GitHub предоставит ссылку на веб-приложение.

## ⚠️ Текущий статус и ограничения

Mafia 2026 находится на стадии прототипа.

Важно учитывать следующие ограничения:

* Реальное сетевое подключение игроков и серверная синхронизация в текущем коде не реализованы.
* Создание комнаты не обеспечивает подключение пользователей с других устройств.
* Игровые участники в текущей версии представлены локальной игровой логикой и ботами.
* Некоторые разделы главного меню предназначены для демонстрации интерфейса и могут не иметь полноценной серверной функциональности.
* Постоянное хранение прогресса и синхронизация профиля между устройствами не подтверждены текущей реализацией.

Таким образом, текущая версия предназначена прежде всего для демонстрации концепции и тестирования игрового процесса в браузере.
