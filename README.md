# Мафия Онлайн
Мультиплеерная «Мафия» на 10–12 игроков с автоматическим ведущим.
## Как играть
- Один игрок жмёт «Создать лобби» и отправляет друзьям 5-значный код.
- Остальные жмут «Присоединиться к лобби» и вводят код
- Не хватает людей — создатель может добавить ботов.
- Голосом удобно общаться параллельно в Discord, а текстовый чат в игре соблюдает очередь речи.
